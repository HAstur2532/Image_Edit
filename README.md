# 图像编辑掩膜生成优化（论文复现与方案分析）

本项目为团队复现 CVPR 2024《Text-Driven Image Editing via Learnable Regions》。

## 我的角色

- 论文精读，梳理 RGN 自动生成编辑区域、CLIP 组合损失指导训练的方法框架
- 参与改进方案讨论：针对 `max_window_size=10` 时结构约束失效、`=8` 时掩膜覆盖不全的 Bad Case，讨论引入 U²-Net 生成软掩膜、以轮廓级掩膜替代方形边界框的改进思路
- 独立撰写技术报告，涵盖复现过程、超参调优记录、改进方案与局限分析

## 仓库内容

- `README.md`：项目说明与角色分工
- `报告.pdf`：完整技术报告，包含复现过程、超参调优记录、改进方案与局限分析

实验代码由队友实现，本仓库主要存放技术报告与复现记录。
